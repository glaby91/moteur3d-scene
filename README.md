# CSE WARP V17 reference scene

Standalone data repository for the V17 civic reference scene. Initial package revision: V17.605. The scene is released independently from the engine and is intended to be fetched by all Moteur3D V17 backends, including LumaTrace.

The `publish-scene.yml` workflow packages `benchmark-civic/` and publishes the latest scene asset as `V17-scene.zip`.
