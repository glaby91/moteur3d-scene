# CSP001 — branche préparatoire
Aucune compilation ni publication automatique dans ce commit. Construire ultérieurement la cible CMake cse_scene_precompiler du moteur au commit 1d3f169e6c15a9f009ef897cdef7e94f0aa2ac4d, avec le même Qt/MSVC que le moteur consommateur. Fournir PATH pour les DLL moteur et Qt et QT_PLUGIN_PATH pour les formats d'image.

Commande (après compilation autorisée):
```
python tools/prepare_scene_release.py --output dist --source-commit <scene SHA> --repository glaby91/moteur3d-scene --precompiler <cse_scene_precompiler.exe> --engine-commit 1d3f169e6c15a9f009ef897cdef7e94f0aa2ac4d
```
Le script appelle le précompilateur après toutes les corrections de scène, valide tailles et empreintes, ajoute les tables au ZIP et enrichit le manifeste. Sans ces arguments, le pipeline reste inchangé. La révision source n'est pas modifiée; avant publication publique il faudra une nouvelle révision de package reconnue par l'updater (qui compare la révision de scène). Le catalogue optique est expérimental et non consommé par le shader; seuls BVH2/BVH4/ordre sont chargés par CSP001. Aucun gain de performance mesuré.
